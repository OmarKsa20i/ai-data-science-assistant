---

## 📖 Overview

AI Data Science Assistant is an interactive application designed to simplify data analysis and machine learning tasks. It provides a user-friendly interface that allows users to upload datasets, clean data, visualize insights, train machine learning models, evaluate model performance, save trained models, and make predictions without writing complex code.

---

## ✨ Features

### 📂 Data Management
- Upload CSV datasets
- Dataset preview
- Dataset information
- Missing values detection
- Duplicate detection
- Data cleaning

### 📊 Data Analysis
- Descriptive statistics
- Correlation matrix
- Interactive data visualization
- Smart chart recommendation

### 🤖 Machine Learning
- Automatic Machine Learning task detection
- AI model recommendation
- Data preprocessing
- Train/Test Split
- Regression models
- Classification models
- Model evaluation

### 🔮 Prediction
- Predict new data
- Save trained models
- Load trained models
